System Features

01

Multi-Sensor Array

BMP280 (Temp/Pressure), TSL2561 (Ambient Light), MQ135 (Gas Quality), AHT20 (Humidity) — all calibrated for accuracy

02

I2C Bus Architecture

Custom TWI implementation at 100kHz with proper pull-up resistors and address decoding

03

Zigbee Telemetry

Xbee S2 module for wireless mesh network communication with coordinator and end-device topologies

04

Real-Time Dashboard

Flask web application with serial communication for live sensor data visualization

05

Low-Power Design

ATmega128 @ 8MHz with optimized sensor reading cycles and sleep mode capabilities

06

Sensor Calibration

BMP280 temperature compensation, TSL2561 dual-channel lux calculation, MQ135 Rs/R0 ratio methods

Technical Specifications

Microcontroller ATmega128 @ 8MHz, 128KB Flash, 4KB SRAM
Sensors BMP280, TSL2561, MQ135, AHT20
Communication I2C (TWI) @ 100kHz, UART @ 9600 bps, Zigbee (Xbee S2)
ADC Resolution 10-bit (0-1023), 8-channel multiplexer
Power Supply 5V DC, compatible with 3.3V sensors
Data Output Temperature, Pressure, Humidity, Lux, CO₂, NH₃, NOₓ, Benzene, Alcohol
Firmware 336 lines embedded C, Atmel Studio
Dashboard Flask + Python, serial communication, 1s refresh
