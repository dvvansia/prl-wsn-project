Wireless Sensor Node for Space Applications

ATmega128-based multi-sensor environmental monitoring system developed at Physical Research Laboratory (PRL), ISRO

View on GitHubLearn More

Project Overview

Developed during internship at Physical Research Laboratory (PRL), ISRO (January-April 2025). Integrates BMP280, TSL2561, MQ135, AHT20 sensors with ATmega128, featuring I2C, UART, and Zigbee wireless.

Key Features

🌡️

Multi-Sensor

BMP280, TSL2561, MQ135, AHT20

🔗

I2C Communication

Custom TWI at 100kHz

📡

Zigbee Wireless

Xbee S2 module

💻

Dashboard

Flask web application

⚡

Low-Power

ATmega128 @ 8MHz

📊

Calibration

Temperature, pressure, lux compensation
