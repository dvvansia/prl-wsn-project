# Wireless Sensor Node Project - PRL ISRO

**Internship:** Physical Research Laboratory (PRL), ISRO  
**Duration:** January 2025 - April 2025  
**Developer:** Dhruvrajsinh Vansia

## Overview
ATmega128-based multi-sensor environmental monitoring system with I2C, UART and Zigbee communication.

## Features
- BMP280, TSL2561, MQ135, AHT20 sensors
- Custom I2C (TWI) implementation at 100kHz
- Zigbee wireless communication (Xbee S2)
- Flask real-time dashboard

## Hardware
- Microcontroller: ATmega128 @ 8MHz
- ADC: 10-bit resolution
- UART: 9600 bps
